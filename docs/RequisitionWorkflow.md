# Requisition approval workflow

1. A requester saves a draft.
2. Submission freezes normal editing and creates three approval assignments.
3. Hiring Manager approval activates the Second approver step.
4. Second approver approval activates HR.
5. HR approval marks the requisition approved.

Reject ends the workflow as rejected. Send Back returns it to draft for correction. Cancel is available before completion; Close records the end of an approved/open hiring requirement. Approval and activity history are append-only.
